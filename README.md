# ⭐ 家事ポイント

**家のお手伝いをすると、ポイントがたまる家族アプリ。**

家事をやったら記録してポイントゲット。たまったポイントは、家族で決めたごほうびと交換できます。

👉 **アプリを開く：https://monsterroberxi11-bot.github.io/kaji-points/**

スマホのブラウザで開いて「ホーム画面に追加」すると、ふつうのアプリみたいに使えます。

---

## できること

- ✅ **記録**：やった家事をタップして記録。毎日やる家事は「今日やった？」がひと目でわかる
- 📷 **証拠写真**：やったあとの写真をつけられる
- 🏆 **ホーム**：家族のランキング、がんばり度のグラフ（7日・30日）、🔥連続記録
- 🎁 **交換**：たまったポイントを、家族で決めたごほうびと交換
- 🤝 **受け渡し**：ごほうびを渡したかどうかを記録。注文が入ると親にメールでお知らせ
- 🔄 **担当ローテーション**：家事の担当が1週間ごとに自動で交代
- 🕒 **履歴**：だれがいつ何をしたか、ぜんぶ残る（消さずに追記するだけなので安心）
- 💬 **要望**：アプリの中から作った人に要望を送れる
